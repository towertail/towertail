This release adds disk usage: find what uses the disk space of a host, and get a cleanup script.

## What is new

- **Usage view.** In Full View, open DISK and select **Usage**. Towertail scans a folder of the host and shows a map of the folders by size. Click a folder to open it.
- **Read-only scans.** The `towertail-sampler scan` command reads the file sizes. It deletes nothing, and it does not read the contents of files.
- **Recommendations.** Towertail shows caches, logs, old releases and other items that you can remove. The list has two groups: "Safe to remove" and "Review first".
- **Cleanup script.** Select items, then click **Copy script**. Paste the script into a terminal on the host. The script stops on a different host, and it tells which lines need `sudo`. Towertail never runs the script.
- **Linux, macOS and Windows hosts.** The rules know the usual caches of each OS, for example apt, Homebrew, Xcode, npm, pip, Go and Docker.
- **Through the server.** When the app uses the self-hosted server, the sampler of the host runs the scan. Turn on "Allow disk scans" for the node, and run the sampler with `--allow-disk-scan`.
- The app bundles [towertail/sampler v1.1.0](https://github.com/towertail/sampler/releases/tag/v1.1.0). Before a scan, the app updates the sampler on the host when the sampler is old.

## Known limits

- On this Mac, macOS blocks some folders (Mail, Messages, Safari) until you give Towertail Full Disk Access. The map shows these folders as "No access".
- A scan of a large disk can take one minute or more.
- The Windows app has no release.

Report problems on [GitHub Issues](https://github.com/towertail/towertail/issues).
